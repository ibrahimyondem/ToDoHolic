# ToDoHolic

ToDoHolic is an iOS task management app built with SwiftUI and CoreData for COMP3097 Mobile App Development II.

## Team Members
- Ibrahim Yondem (101525165)
- Baris Isci (101531238)

## Features
- Launch screen with app name and team members
- Welcome screen that stores the user's name locally
- Dashboard with emoji categories and task counts
- Add task screen with title, due date/time, and category selection
- Task list screen with overdue, due soon, upcoming, and completed status
- Edit task support
- Delete confirmation and error alerts

## Data Stored
- User name
- Task title
- Due date and time
- Task category
- Task completion status

## Storage
The app uses CoreData for local persistence so tasks remain available after the app is closed.

## Notes
The app is designed for iPhone portrait mode and optimized for a clean, simple user experience.
